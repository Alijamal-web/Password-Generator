# Password Generator

## About the Project
Password Generator is a simple Python-based project that allows users to create random passwords of their desired length. The program generates passwords using a combination of uppercase and lowercase letters, numbers, and special characters.

## Features
- Custom password length.
- Random character selection.
- Uppercase and lowercase letters.
- Numbers and special characters.
- Automatic password generation.

## Technologies Used
- Python
- Random module

## How to Run
1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run the following command:

`python main.py`

## How to Use
1. Run the program.
2. Enter your desired password length.
3. The program randomly selects characters.
4. Your generated password will appear in the terminal.
